# Aarish Shaheen | Academic Portfolio

This repository contains the source code for my personal academic website and technical blog, hosted at [bertramwooster.github.io](https://bertramwooster.github.io). 

Built with Jekyll and the al-folio academic theme, the site serves as a central hub for my research, teaching materials, and algorithmic implementations.

## Overview
I am an Assistant Professor of Electrical Engineering at the University of Kashmir. My research focuses on the intersection of power system dynamics and machine learning, specifically zero-allocation robust dynamic synchrophasor state estimation and physics-informed manifold embeddings for real-time grid monitoring. 

I also lead the development of **KashmirBuild**, an open-source building energy efficiency platform tailored to Kashmir's cold climate.
